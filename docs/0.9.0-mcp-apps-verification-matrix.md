# 0.9.0 MCP Apps verification matrix

Status: working release gate, not host or production proof. Scope is the owner-approved self-hosted, per-site, opt-in pilot. Record the tested commit and exact ZIP hash before changing any row to passed. A local fixture pass is not a claim that ChatGPT or another host renders the card.

| Untrusted result rendering | HTML/script-like site names and malformed structured/text content cannot execute or alter the page; loading, error, cancellation and teardown are safe. | Isolated Playwright/Chromium harness passes message initialization, tool result, script-like site name escaping, cancellation, theme change and page-error checks.
